`UiNavbar` is a composable top navigation bar. Assemble it from brand, nav, link, avatar, and toggle sub-components.

## Build a navbar

```vue
<script setup lang="ts">
import { NuxtLink } from '#components'
</script>

<template>
  <UiNavbar sticky aria-label="Main navigation">
    <UiNavbarBrand :as="NuxtLink" to="/" text="Acme" logo="/logo.svg" />

    <UiNavbarNav position="start">
      <UiNavbarItem>
        <UiNavbarLink :as="NuxtLink" to="/docs" text="Docs" />
      </UiNavbarItem>
      <UiNavbarItem>
        <UiNavbarLink :as="NuxtLink" to="/pricing" text="Pricing" />
      </UiNavbarItem>
    </UiNavbarNav>

    <UiNavbarNav position="end">
      <UiNavbarAvatar src="/me.jpg" alt="Account" @click="openMenu" />
    </UiNavbarNav>
  </UiNavbar>
</template>
```

## Toggle a sidebar

`UiNavbarToggle` pairs with [`UiSidebar`](/colorffy-ui/components/sidebar)'s `open` state:

```vue
<template>
  <UiNavbarToggle :collapsed="open" controls="main-sidebar" @toggle="open = !open" />
</template>
```

## UiNavbar props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sticky` | `boolean` | `false` | Sticky positioning. |
| `fluid` | `boolean` | `false` | Fluid (full-width) container. |
| `ariaLabel` | `string` | `'Main navigation'` | Landmark name. |

## Sub-components

| Component | Key props |
|-----------|-----------|
| `UiNavbarBrand` | `logo`, `initials`, `text`, `as`, `to` / `href` |
| `UiNavbarNav` | `position` (`'start'` / `'end'`) |
| `UiNavbarItem` | `customClass` |
| `UiNavbarLink` | `text`, `icon`, `to` / `href`, `as`, `active` |
| `UiNavbarTitle` | `title` |
| `UiNavbarAvatar` | `src`, `alt`, `size` (`'sm'` / `'navbar'`); emits `click` |
| `UiNavbarToggle` | `collapsed`, `controls`, `collapseText`, `expandText`; emits `toggle` |
| `UiNavbarCollapse`, `UiNavbarMobileMenu` | `customClass` |

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the navbars inside it. Variants such as `nav-island` and `nav-transparent` keep their own background and radius.

```css
:root {
  --navbar-bg-color: var(--theme-surface-container-low);
  --navbar-link-active-bg-color: var(--theme-primary-a10);
  --navbar-link-active-color: var(--theme-on-primary);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--navbar-bg-color` | `--theme-background` | Background |
| `--navbar-color` | `--theme-on-background` | Brand and title text color |
| `--navbar-shadow` | `none` | Shadow |
| `--navbar-radius` | `--radius-none` | Corner radius (links follow it) |
| `--navbar-padding-inline` / `--navbar-padding-block` | `0` / `--space-8` | Inner padding |
| `--navbar-margin-block-end` | the block padding | Space below the navbar |
| `--navbar-min-height` | `4.25rem` | Minimum height |
| `--navbar-easing` / `--navbar-duration` | `--ease-emphasized` / `--duration-600` | Background and collapse transitions |
| `--navbar-brand-font-size` / `--navbar-brand-font-weight` | `--fs-sm` / `--fw-800` | Brand text |
| `--navbar-brand-size` | `50px` | Maximum logo width and height |
| `--navbar-brand-hover-color` | `--theme-primary-a20` | Brand color on hover |
| `--navbar-title-font-size` / `--navbar-title-font-weight` | `--fs-sm` / `--fw-600` | Page title |
| `--navbar-link-color` | `--theme-muted-a10` | Link text |
| `--navbar-link-hover-color` / `--navbar-link-hover-bg-color` | `--theme-primary-a10` / `--theme-surface-container-high` | Hovered link |
| `--navbar-link-active-color` / `--navbar-link-active-bg-color` | `--theme-primary-a10` / `--theme-surface-container` | Current-page link (its border follows the background) |
| `--navbar-link-font-size` / `--navbar-link-font-weight` | `--fs-xs` / `--fw-600` | Link text |
| `--navbar-link-radius` | navbar radius + `.5rem` | Link corners |
| `--navbar-link-padding-inline` / `--navbar-link-padding-block` | `0` (`--space-8` from 992px) / `--space-8` | Link padding |
