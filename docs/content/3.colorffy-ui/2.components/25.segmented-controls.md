`UiSegmentedControls` switches between a small number of options with an animated active indicator.

## Add segmented controls

```vue
<script setup lang="ts">
import type { ISegmentedTab } from '@colorffy/ui'
import { ref } from 'vue'

const tabs: ISegmentedTab[] = [
  { id: 'all', label: 'All' },
  { id: 'active', label: 'Active' },
  { id: 'archived', label: 'Archived' },
]
const active = ref('all')
</script>

<template>
  <UiSegmentedControls :tabs="tabs" :active-tab="active" @update-active-tab="active = $event" />
</template>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tabs` | `ISegmentedTab[]` | — | Items: `{ id, label, disabled? }`. |
| `activeTab` | `string` | first tab | Active tab id. |

**Emits:** `updateActiveTab(tabId)`.

::note
The pill is positioned and animated with pure CSS anchor positioning, so it reads the active tab's real geometry — no offsets to keep in sync and no JavaScript. `ISegmentedTab.position` is deprecated and ignored; it will be removed in v3. Where anchor positioning is unsupported, the active tab falls back to a bolder label on a filled background.
::

::tip
For standard underline-style tabs, use [`UiTabs`](/colorffy-ui/components/tabs).
::
