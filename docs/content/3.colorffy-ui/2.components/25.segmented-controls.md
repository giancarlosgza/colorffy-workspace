`UiSegmentedControls` switches between a small number of options with an animated active indicator.

## Add segmented controls

```vue
<script setup lang="ts">
import type { ISegmentedTab } from '@colorffy/ui'
import { ref } from 'vue'

const tabs: ISegmentedTab[] = [
  { id: 'all', label: 'All' },
  { id: 'active', label: 'Active' },
  { id: 'archived', label: 'Archived' },
]
const active = ref('all')
</script>

<template>
  <UiSegmentedControls :tabs="tabs" :active-tab="active" @update-active-tab="active = $event" />
</template>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tabs` | `ISegmentedTab[]` | — | Items: `{ id, label, disabled? }`. |
| `activeTab` | `string` | first tab | Active tab id. |

**Emits:** `updateActiveTab(tabId)`.

::note
The pill is positioned and animated with pure CSS anchor positioning, so it reads the active tab's real geometry — no offsets to keep in sync and no JavaScript. `ISegmentedTab.position` is deprecated and ignored; it will be removed in v3. Where anchor positioning is unsupported, the active tab falls back to a bolder label on a filled background.
::

::tip
For standard underline-style tabs, use [`UiTabs`](/colorffy-ui/components/tabs).
::

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the controls inside it. The tab style (`segmented-control-tab`) keeps its own square corners, borderless frame and underline bar.

```css
:root {
  --segmented-control-indicator-bg-color: var(--theme-primary-a10);
  --segmented-control-item-active-color: var(--theme-on-primary);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--segmented-control-radius` | `--radius-full` | Container and item corners |
| `--segmented-control-border-color` | `--theme-outline-button` | Container border |
| `--segmented-control-padding` / `--segmented-control-gap` | `--space-8` / `--space-12` | Container padding and space between items |
| `--segmented-control-item-color` / `--segmented-control-item-font-size` | `--theme-muted-a10` / `--fs-2xs` | Item text |
| `--segmented-control-item-hover-bg-color` | primary tint | Hovered item |
| `--segmented-control-item-active-color` | `--theme-on-background-inverse` | Selected item text |
| `--segmented-control-indicator-bg-color` | `--theme-surface-a90` | Sliding pill behind the selected item |
| `--segmented-control-easing` / `--segmented-control-duration` | `--ease-emphasized` / `--duration-600` | Pill slide and color transitions |
