Colorffy UI provides three icon components. All take `decorative` and `ariaLabel` (required when `decorative` is `false`). `UiIconSvg` and `UiIconShapes` also take a `size`, and `UiIconSvg` a `color` and a `uid` that namespaces IDs inside inlined SVG markup.

## Material Symbols

Pass a Material Symbols entity code. The glyph follows the surrounding text, so size and color it with a class or an inline style:

```vue
<template>
  <UiIconMaterial icon-code="&#xe88a;" />
  <UiIconMaterial icon-code="&#xe838;" class="text-primary" style="font-size: 2rem" />
</template>
```

## Decorative shapes

Shapes keep their own gradients, so `color` has no effect on them:

```vue
<template>
  <UiIconShapes shape="blob-3" />
  <UiIconShapes shape="star-5" size="lg" />
  <UiIconShapes shape="circle-2" :size="96" />
</template>
```

## Custom SVG

Paste any inline `<svg>` (e.g. from [thesvg.org](https://thesvg.org)) into the default slot, or pass raw markup via `content` for data-driven icons from your own local registry:

```vue
<template>
  <!-- Slot: paste the SVG directly -->
  <UiIconSvg :size="32">
    <svg viewBox="0 0 24 24" fill="currentColor"><path d="…" /></svg>
  </UiIconSvg>

  <!-- content: for data-driven lists -->
  <UiIconSvg v-for="logo in logos" :key="logo.name" :content="logo.svg" />
</template>
```

`color` recolors monochrome icons via `currentColor`; multi-color SVGs keep their own fills.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `decorative` | `boolean` | `true` | Hide from assistive tech. |
| `ariaLabel` | `string \| null` | — | Required when `decorative` is `false`. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| number` | `'md'` | `UiIconSvg`: 20 / 24 / 32 / 40 / 48px. `UiIconShapes`: 24 / 32 / 45 / 64 / 80px. A number is px. `UiIconMaterial` ignores it. |
| `color` | `string \| null` | `currentColor` | `UiIconSvg` only: any CSS color. |
| `uid` | `string \| null` | generated with `useId()` | `UiIconSvg` only: namespace seed for IDs inside inlined SVG markup. |

## Per-component prop

| Component | Required prop | Values |
|-----------|---------------|--------|
| `UiIconMaterial` | `iconCode` | Material Symbols entity (e.g. `&#xe88a;`) |
| `UiIconShapes` | `shape` | `blob-1`…`blob-7`, `star-1`…`star-8`, `circle-1`…`circle-4`, `shape-1`…`shape-4`, `lighting-1` |
| `UiIconSvg` | slot or `content` | Any inline `<svg>` markup — pasted in the slot, or a raw string via `content`; `uid` namespaces internal SVG IDs |
