`UiPagination` renders a `<nav>` of page buttons. Bind the current page with `v-model:page` (pages start at 1) and give it either the item count and page size, or the page count. The current page gets `aria-current="page"`.

## Add a pagination

```vue
<script setup lang="ts">
import { ref } from 'vue'

const page = ref(1)
</script>

<template>
  <UiPagination v-model:page="page" :total="248" :page-size="20" />
</template>
```

When the page count drops below the current page, for example after a filter, the pagination moves to the last page and emits `update:page`.

## Page on the server

Pass `totalPages` when the server sends a page count, and fetch the page whenever it changes:

```vue
<script setup lang="ts">
const page = ref(1)
const { data } = await useFetch('/api/invoices', { query: { page } })
</script>

<template>
  <UiDatatable :columns="columns" :items="data?.items ?? []" />
  <UiPagination
    v-model:page="page"
    :total-pages="data?.pageCount ?? 1"
    class="d-flex justify-content-end mt-3"
  />
</template>
```

To page rows that are already loaded, use the datatable's [`pagination`](/colorffy-ui/components/datatable#split-rows-into-pages) prop instead.

## Collapse long ranges

The first and last pages always show, with `siblingCount` pages on each side of the current one (default `1`). The pages in between collapse into an ellipsis. An ellipsis never hides a single page, and the number of buttons stays the same from page to page, so the arrows don't move under the pointer.

```vue
<template>
  <!-- 1 … 8 9 10 11 12 … 20 -->
  <UiPagination v-model:page="page" :total-pages="20" :sibling-count="2" />
</template>
```

`showEdges` adds first-page and last-page buttons next to the arrows.

## Compact layout

On screens narrower than 600px, the page numbers give way to the position text: `‹ Page 3 of 12 ›`. Set `compact` to use that layout at every width, for example in a narrow card:

```vue
<template>
  <UiPagination v-model:page="page" :total-pages="12" compact show-edges />
</template>
```

## Translate the labels

`labels` takes any of `first`, `previous`, `next`, `last` (the arrow buttons' accessible names) and `status` (the position text). To translate every pagination at once, set them app-wide; see [Localization](/colorffy-ui/localization). In `status`, `{page}` and `{total}` are replaced with numbers, so the words can come in any order:

```vue
<template>
  <UiPagination
    v-model:page="page"
    :total-pages="8"
    aria-label="Paginación"
    :labels="{ previous: 'Página anterior', next: 'Página siguiente', status: 'Página {page} de {total}' }"
  />
</template>
```

## Accessibility

- At the first or last page, the arrows that can't move are marked `aria-disabled` instead of `disabled`, so keyboard focus stays on the arrow you just pressed.
- Moving to another page announces the position text through a polite live region.
- Give each pagination on a page its own `ariaLabel`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `page` | `number` | `1` | Current page, starting at 1. Bind with `v-model:page`. |
| `total` | `number` | `0` | Number of items. With `pageSize`, sets the page count. |
| `pageSize` | `number` | `10` | Items per page. |
| `totalPages` | `number \| null` | `null` | Page count. Takes precedence over `total` and `pageSize`. |
| `siblingCount` | `number` | `1` | Pages shown on each side of the current page. |
| `showEdges` | `boolean` | `false` | Add first-page and last-page buttons. |
| `compact` | `boolean` | `false` | Show the position text instead of page numbers at every width. |
| `size` | `'sm' \| 'md' \| 'lg' \| null` | `'sm'` | Button size. |
| `disabled` | `boolean` | `false` | Disable every button. |
| `ariaLabel` | `string` | `'Pagination'` | `<nav>` landmark name. |
| `labels` | `Partial<IPaginationLabels> \| null` | `null` | Text for the arrows and the position text. |
| `customClass` | `ClassValue \| null` | `null` | Classes for the `<nav>`. |

**Labels (`IPaginationLabels`):** `first` (`'First page'`), `previous` (`'Previous page'`), `next` (`'Next page'`), `last` (`'Last page'`), `status` (`'Page {page} of {total}'`).
**Emits:** `update:page(page)`.

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the paginations inside it. The page buttons are `.btn` elements, so their size and hover come from the [button](/colorffy-ui/components/button) styles.

```css
:root {
  --cffy-pagination-radius: var(--cffy-radius-sm);
  --cffy-pagination-current-bg-color: var(--cffy-primary-container);
  --cffy-pagination-current-color: var(--cffy-on-primary-container);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-pagination-gap` | `--cffy-space-4` | Space between buttons |
| `--cffy-pagination-radius` | `--cffy-radius-full` | Button corners |
| `--cffy-pagination-current-bg-color` / `--cffy-pagination-current-color` | `--cffy-primary-a10` / `--cffy-on-primary` | Current page |
| `--cffy-pagination-status-color` | `--cffy-on-background` | Position text in the compact layout |
