`UiHeaderContent` renders a page header (title, subtitle, optional back button and actions). `UiHeroContent` is its page-opening counterpart, with a display-sized title and CTA slot. `UiSubheadingContent` labels a section inside a page. `UiPaneContent` is a content container with a row/column layout.

## Add a page header

```vue
<template>
  <UiHeaderContent
    title="Projects"
    subtitle="Manage your team's work"
    back-button
    @back="goBack"
  >
    <template #actions>
      <UiButton variant="filled" color="primary" text="New" />
    </template>
  </UiHeaderContent>
</template>
```

## Wrap content in a pane

```vue
<template>
  <UiPaneContent is-full-height aria-label="Project list">
    <!-- content -->
  </UiPaneContent>
</template>
```

## UiHeaderContent props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `string` | `'h1'` | Heading element for the title. Section headers inside a page should step down from the page's own `h1`. |
| `headingId` | `string` | generated with `useId()` | ID for the heading, for external `aria-labelledby` references. |
| `headline` | `string \| null` | — | Small eyebrow label above the title, rendered with `caption text-primary`. |
| `title` | `string \| null` | — | Header title. |
| `subtitle` | `string \| null` | — | Header subtitle. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `'sm'` | Title size: `sm` is `--fs-xl`, then `--fs-2xl` … `--fs-5xl`. Each step also takes the line height the type scale pairs with it. |
| `hideActionsWhenNarrow` | `boolean` | `false` | Drop the actions from the layout once the header's container is 700px or narrower, instead of wrapping them below the title. |
| `backButton` | `boolean` | `false` | Show a back button. |
| `backButtonLabel` | `string` | `'Go back'` | Back button tooltip. |
| `containerClass` | `string \| string[] \| Record<string, boolean>` | — | Extra classes. |

**Emits:** `back` (back button). **Slots:** `#actions` — filling it is what renders the actions area; there is no flag to set.

## Open a page with a hero

`size` uses the same `sm`–`xl` vocabulary as `UiHeaderContent`, mapped onto the
display scale, and `align` moves the whole block, text and actions together.

```vue
<template>
  <UiHeroContent
    headline="Open source"
    title="Build vibrant interfaces"
    subtitle="70+ headless components for Vue 3 and Nuxt."
    size="lg"
    align="center"
  >
    <template #actions>
      <UiButton variant="filled" color="primary" text="Get started" />
      <UiButton variant="outline" text="Documentation" />
    </template>
  </UiHeroContent>
</template>
```

## UiHeroContent props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `headingId` | `string` | generated with `useId()` | ID for the title; the `<section>` references it with `aria-labelledby`. |
| `headline` | `string \| null` | — | Small eyebrow label above the title. |
| `title` | `string \| null` | — | Main title, rendered with the display class. |
| `subtitle` | `string \| null` | — | Supporting description. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'xl'` | Title size on the display scale: `sm` is `display-4`, `xl` is `display-1`. |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Alignment of the whole hero. |
| `customClass` | `string \| string[] \| Record<string, boolean>` | — | Extra classes. |

**Slots:** `#actions` for the call-to-action buttons.

## Label a section

```vue
<template>
  <UiSubheadingContent
    title="Integrations"
    subtitle="Connect the tools your team already uses."
  >
    <template #actions>
      <UiBadge text="3 active" variant="outline" size="sm" />
    </template>
  </UiSubheadingContent>
</template>
```

## UiSubheadingContent props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `string` | `'h3'` | Heading element, so the page keeps a valid heading order. |
| `title` | `string \| null` | — | Subheading text, rendered with `.text-subheading`. |
| `subtitle` | `string \| null` | — | Description; picks up the muted styling by being the heading's sibling. |
| `gutter` | `'none' \| 'sm' \| 'md'` | `'md'` | Space below the block. The title-to-description gap is fixed and does not follow it. |
| `customClass` | `string \| string[] \| Record<string, boolean>` | — | Extra classes for the wrapper. |

**Slots:** `#actions` — a badge or control beside the subheading; the wrapper switches to two columns when it is filled.

## UiPaneContent props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isFullHeight` | `boolean` | `false` | Expand to full height. |
| `customClass` / `containerClass` | `string \| string[] \| Record<string, boolean>` | — | Extra classes. |
| `ariaLabel` / `ariaLabelledby` / `ariaDescribedby` | `string` | — | ARIA wiring. |
