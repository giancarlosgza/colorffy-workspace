`UiButtonMenu` renders a button that opens a dropdown. Fill it with `UiButtonMenuItem`, `UiButtonMenuSubmenu`, `UiButtonMenuDivider`, and `UiButtonMenuText`.

## Build a menu

```vue
<template>
  <UiButtonMenu variant="outline" text="Actions">
    <UiButtonMenuText item-text="Manage" />
    <UiButtonMenuItem item-text="Edit" icon="&#xe3c9;" />
    <UiButtonMenuItem item-text="Duplicate" icon="&#xe14d;" shortcut="Ctrl+D" />
    <UiButtonMenuDivider />
    <UiButtonMenuItem item-text="Delete" icon="&#xe872;" is-destructive />
  </UiButtonMenu>
</template>
```

## Add a submenu

```vue
<template>
  <UiButtonMenu text="More">
    <UiButtonMenuItem item-text="Share" icon="&#xe80d;" />
    <UiButtonMenuSubmenu item-text="Export" icon="&#xe2c6;" placement="right">
      <UiButtonMenuItem item-text="PDF" />
      <UiButtonMenuItem item-text="CSV" />
    </UiButtonMenuSubmenu>
  </UiButtonMenu>
</template>
```

## UiButtonMenu props

Extends [`UiButton`](/colorffy-ui/components/button) props, plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isMobile` | `boolean` | — | Disable some positioning features on mobile. |
| `tooltipPlacement` | `Placement` | — | Tooltip placement (`top`, `bottom`, `left`, `right`, …). |

**Emits:** `onClick`.

## UiButtonMenuItem props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `itemText` | `string` | — | Item label. |
| `icon` | `string \| null` | — | Leading Material Symbols code. |
| `iconTrailing` | `string \| null` | — | Trailing icon code. |
| `badge` | `Partial<IBadgeProps> \| null` | — | Inline badge config. |
| `shortcut` | `string \| null` | — | Shortcut hint (e.g. `Ctrl+S`). |
| `isDestructive` | `boolean` | `false` | Destructive (danger) styling. |
| `disabled` | `boolean` | `false` | Disable the item. |

## CSS variables

The menu panel (`.v-popper--theme-dropdown`, shared by every dropdown) reads these variables. Set them on `:root` to restyle all menus. The mobile bottom sheet keeps its larger item padding and corners. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

```css
:root {
  --dropdown-radius: var(--radius-md);
  --dropdown-item-hover-color: var(--theme-primary-a10);
  --dropdown-item-hover-color: var(--theme-on-primary);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--dropdown-bg-color` / `--dropdown-color` | `--theme-surface-overlay` / `--theme-on-background` | Panel background and text |
| `--dropdown-border-color` | `--theme-outline-overlay` | Panel border |
| `--dropdown-radius` | `--radius-lg` | Panel corners (items use half) |
| `--dropdown-shadow` | `--shadow-lg` | Panel shadow |
| `--dropdown-padding` | `--space-4` | Panel padding |
| `--dropdown-min-width` | `12rem` | Panel minimum width |
| `--dropdown-easing` / `--dropdown-duration` | `--ease-overshoot-soft` / `--duration-500` | Opening animation |
| `--dropdown-item-color` | the panel text color | Item text |
| `--dropdown-item-font-size` | `--fs-3xs` | Item text size |
| `--dropdown-item-radius` | half the panel radius | Item corners |
| `--dropdown-item-padding-inline` / `--dropdown-item-padding-block` | `--space-8` / `--space-8` | Item padding |
| `--dropdown-item-hover-color` | `--theme-on-background` | Hovered item text |
| `--dropdown-item-active-color` / `--dropdown-item-active-bg-color` | `--theme-on-background` / `--theme-surface-container-highest` | Selected, focused and pressed item |

## Related components

- `UiButtonMenuSubmenu` — nested submenu (`itemText`, `icon`, `placement`, …).
- `UiButtonMenuDivider` — visual separator.
- `UiButtonMenuText` — non-interactive label (`itemText`).
