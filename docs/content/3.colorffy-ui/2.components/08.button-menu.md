`UiButtonMenu` renders a button that opens a dropdown. Fill its `#menu` slot with `UiButtonMenuItem`, `UiButtonMenuSubmenu`, `UiButtonMenuDivider`, and `UiButtonMenuText`; items take their label from `item-text`.

## Build a menu

```vue
<template>
  <UiButtonMenu variant="outline" text="Actions">
    <template #menu>
      <UiButtonMenuText item-text="Manage" />
      <UiButtonMenuItem item-text="Edit" icon="&#xe3c9;" />
      <UiButtonMenuItem item-text="Duplicate" icon="&#xe14d;" shortcut="Ctrl+D" />
      <UiButtonMenuDivider />
      <UiButtonMenuItem item-text="Delete" icon="&#xe872;" is-destructive />
    </template>
  </UiButtonMenu>
</template>
```

## Add a submenu

```vue
<template>
  <UiButtonMenu text="More">
    <template #menu>
      <UiButtonMenuItem item-text="Share" icon="&#xe80d;" />
      <UiButtonMenuSubmenu item-text="Export" icon="&#xe2c6;" placement="right">
        <UiButtonMenuItem item-text="PDF" />
        <UiButtonMenuItem item-text="CSV" />
      </UiButtonMenuSubmenu>
    </template>
  </UiButtonMenu>
</template>
```

## UiButtonMenu props

Takes [`UiButton`](/colorffy-ui/components/button)'s look and state props (`id`, `text`, `title`, `variant`, `color`, `size`, `icon`, `iconVariant`, `iconTrailing`, `disabled`, `loading`, `rounded`, `fluid`, `customClass`). The trigger is always a button, so the link props (`to`, `href`, `as`) and `type` don't apply. It adds:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placement` | `Placement` | `'bottom'` | Dropdown placement (`top`, `bottom`, `left`, `right`, …). |
| `tooltipText` | `string \| null` | `'menu'` | Tooltip on the trigger, and its accessible name when there is no `text` or `title`. |
| `tooltipPlacement` | `Placement` | `'top'` | Tooltip placement. |
| `isMobile` | `boolean` | `false` | Disable dropdown positioning (bottom sheet on mobile). |

**Slots:** `menu` (the dropdown content), `icon` (the trigger icon).
**Emits:** `click` (with the `MouseEvent`).

## UiButtonMenuItem props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `itemText` | `string` | — | Item label. |
| `icon` | `string \| null` | — | Leading Material Symbols code. |
| `iconTrailing` | `string \| null` | — | Trailing icon code. |
| `badge` | `Partial<IBadgeProps> \| null` | — | Inline badge config. |
| `shortcut` | `string \| null` | — | Shortcut hint (e.g. `Ctrl+S`). |
| `isDestructive` | `boolean` | `false` | Destructive (danger) styling. |
| `disabled` | `boolean` | `false` | Disable the item. |
| `keepOpen` | `boolean` | `false` | Keep the menu open after a click. By default a click closes the menu and any parent submenu. |

## CSS variables

The menu panel (`.v-popper--theme-dropdown`, shared by every dropdown) reads these variables. Set them on `:root` to restyle all menus. The mobile bottom sheet keeps its larger item padding and corners. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

```css
:root {
  --cffy-dropdown-radius: var(--cffy-radius-md);
  --cffy-dropdown-item-active-bg-color: var(--cffy-primary-container);
  --cffy-dropdown-item-active-color: var(--cffy-on-primary-container);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-dropdown-bg-color` / `--cffy-dropdown-color` | `--cffy-surface-overlay` / `--cffy-on-background` | Panel background and text |
| `--cffy-dropdown-border-color` | `--cffy-outline-overlay` | Panel border |
| `--cffy-dropdown-radius` | `--cffy-shape-container` | Panel corners (items use half) |
| `--cffy-dropdown-shadow` | `--cffy-shadow-lg` | Panel shadow |
| `--cffy-dropdown-padding` | `--cffy-space-4` | Panel padding |
| `--cffy-dropdown-min-width` | `12rem` | Panel minimum width |
| `--cffy-dropdown-easing` / `--cffy-dropdown-duration` | `--cffy-ease-overshoot-soft` / `--cffy-duration-500` | Opening animation |
| `--cffy-dropdown-item-color` | the panel text color | Item text |
| `--cffy-dropdown-item-font-size` | `--cffy-fs-3xs` | Item text size |
| `--cffy-dropdown-item-radius` | half the panel radius | Item corners |
| `--cffy-dropdown-item-padding-inline` / `--cffy-dropdown-item-padding-block` | `--cffy-space-8` / `--cffy-space-8` | Item padding |
| `--cffy-dropdown-item-hover-color` | `--cffy-on-background` | Hovered item text |
| `--cffy-dropdown-item-active-color` / `--cffy-dropdown-item-active-bg-color` | `--cffy-on-background` / `--cffy-surface-container-highest` | Selected, focused and pressed item |
