All Colorffy form inputs share a common base — `label`, `placeholder`, `disabled`, `required`, `readonly`, `errorMessages`, `variant`, `size`, `hideLabel` — and bind with `v-model`.

## Text and textarea

```vue
<script setup lang="ts">
import { ref } from 'vue'

const name = ref('')
const bio = ref('')
</script>

<template>
  <UiInputText v-model="name" label="Name" placeholder="Jane Doe" required />
  <UiInputTextarea v-model="bio" label="Bio" :rows="4" />
</template>
```

## Select

`options` accepts an array; map labels / values with `optionLabel` / `optionValue`:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const role = ref(null)
const options = [
  { name: 'Admin', value: 'admin' },
  { name: 'User', value: 'user' },
]
</script>

<template>
  <UiInputSelect
    v-model="role"
    :options="options"
    option-label="name"
    option-value="value"
    label="Role"
  />
</template>
```

## Checkbox, switch, and radio

```vue
<template>
  <UiInputCheck v-model="agree" label="I agree to the terms" required />
  <UiInputCheck v-model="dark" label="Dark mode" variant="switch" />
  <UiInputRadio v-model="plan" :options="plans" option-label="name" option-value="id" inline />
</template>
```

## Range, file, color, and phone

`UiInputFile`, `UiInputColorPicker`, and `UiInputCheck` share the same base props as the other inputs (`errorMessages`, `disabled`, `required`, `optionalLabel`, `hideLabel`) and bind with `v-model` like the rest:

```vue
<template>
  <UiInputRange v-model="volume" :min="0" :max="100" :step="5" label="Volume" />
  <UiInputFile v-model="file" label="Upload" input-label="Choose a file" :error-messages="fileErrors" />
  <UiInputPhoneNumber v-model="phone" label="Phone" />
  <UiInputColorPicker v-model="color" label="Brand color" :maxlength="7" />
</template>
```

`size="sm"` on `UiInputRange` shrinks the track and the thumb along with the field, for dense forms and toolbars:

```vue
<template>
  <UiInputRange v-model="zoom" size="sm" label="Zoom" />
</template>
```

## OTP Input

`UiInputOtp` renders one box per character of a segmented PIN or verification code. It auto-advances focus as boxes fill, supports Backspace/Arrow key navigation, and distributes pasted (or autofilled) codes across boxes. `modelValue` is always a plain string; `length` (default `6`) controls the number of boxes.

```vue
<script setup lang="ts">
import { ref } from 'vue'

const code = ref('')

function handleComplete(value: string) {
  console.log('Code complete:', value)
}
</script>

<template>
  <UiInputOtp v-model="code" label="Verification code" @complete="handleComplete" />
  <UiInputOtp v-model="pin" label="4-digit PIN" :length="4" />
</template>
```

**Props:** `length` (default `6`), `integerOnly` (default `true` — numeric `inputmode`, non-digit characters discarded on input/paste; set to `false` for alphanumeric codes), `autofocus`, plus the shared base props (`errorMessages`, `disabled`, `required`, `readonly`, `variant`, `size`, `rounded`, `hideLabel`).

**Events:** `update:modelValue`, `update`, and `complete` — fired once with the full value when every box is filled.

## Prefix and suffix

`UiInputText` exposes `#prefix` and `#suffix` named slots. Content rendered in either slot gets a bordered box attached to the input — useful for icons or units.

```vue
<template>
  <UiInputText v-model="search" label="Search">
    <template #prefix>
      <UiIconMaterial icon-code="&#xe8b6;" />
    </template>
  </UiInputText>

  <UiInputText v-model="price" label="Price" type="number">
    <template #prefix>
      $
    </template>
    <template #suffix>
      USD
    </template>
  </UiInputText>
</template>
```

## Shared base props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string \| null` | — | Field label. |
| `placeholder` | `string \| null` | — | Placeholder text. |
| `errorMessages` | `string[]` | — | Validation messages shown below the field. |
| `variant` | `'filled' \| 'outline' \| 'transparent' \| null` | — | Visual style. |
| `size` | `'sm' \| 'lg' \| null` | — | Field size. |
| `disabled` / `required` / `readonly` / `rounded` | `boolean` | `false` | Field states. |
| `hideLabel` | `boolean` | `false` | Visually hide the label. |

## Per-input highlights

| Component | Notable props | `v-model` type |
|-----------|---------------|----------------|
| `UiInputText` | `type`, `maxlength`, `min`, `max`, `autofocus` | `string \| number \| null` |
| `UiInputTextarea` | `rows`, `cols`, `resize` | `string \| null` |
| `UiInputSelect` | `options`, `optionLabel`, `optionValue` | `string \| number \| object \| null` |
| `UiInputRadio` | `options`, `optionLabel`, `optionValue`, `inline` | `string \| number \| null` |
| `UiInputRange` | `min`, `max`, `step` | `string \| number \| null` |
| `UiInputCheck` | `variant: 'switch'`, `label` (required) | `string \| boolean \| null` |
| `UiInputFile` | `inputLabel`, `size: 'lg'` (taller dropbox) | `File \| null` |
| `UiInputColorPicker` | `maxlength` | `string \| null` |
| `UiInputPhoneNumber` | `maxlength`, `autofocus` | `string \| null` |
| `UiInputOtp` | `length`, `integerOnly`, `autofocus` | `string` |

::note
Most inputs emit both `update:modelValue` (for `v-model`) and an `update` convenience event with the same payload — this now includes `UiInputCheck`.
::

::note
**Breaking change:** `UiInputColorPicker`'s length-limit prop was renamed from `maxLength` to `maxlength` (lowercase, matching the other text inputs).
::

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the fields inside it. They style text inputs, textareas and selects, and the color picker's field reads the same surface, border, radius and focus variables. The outline, rounded, transparent, `sm` and `lg` styles keep their own values, and disabled fields keep their muted look.

```css
:root {
  --cffy-input-radius: var(--cffy-radius-full);
  --cffy-input-padding-inline: var(--cffy-space-14);
  --cffy-input-focus-border-color: var(--cffy-accent-a10);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-height` | `2.5rem` | Field height |
| `--cffy-input-padding-inline` / `--cffy-input-padding-block` | `--cffy-space-8` / `--cffy-space-4` | Field padding |
| `--cffy-input-radius` | `$form-border-radius` (8px) | Corners |
| `--cffy-input-bg-color` / `--cffy-input-color` | `transparent` / `--cffy-on-background` | Background and text |
| `--cffy-input-border-width` / `--cffy-input-border-color` | `1px` / `--cffy-outline-text-field` | Border |
| `--cffy-input-font-size` | `0.875rem` | Text size |
| `--cffy-input-shadow` | `--cffy-shadow-xs` | Resting shadow |
| `--cffy-input-placeholder-color` | `--cffy-muted-a10` at 65% | Placeholder text |
| `--cffy-input-filled-bg-color` | `--cffy-surface-container-high` | Background of `.form-filled` fields |
| `--cffy-input-hover-border-color` | `--cffy-on-background` | Hovered border |
| `--cffy-input-focus-bg-color` / `--cffy-input-focus-border-color` | `--cffy-surface-container-high` / `--cffy-primary-a10` | Focused field |
| `--cffy-input-focus-ring-color` | `--cffy-primary-base-fixed` at 25% | Focus ring |
| `--cffy-input-invalid-color` / `--cffy-input-invalid-ring-color` | `--cffy-danger-a10` / `--cffy-danger-base-fixed` at 25% | Invalid border and message, and its focus ring |
| `--cffy-input-easing` / `--cffy-input-duration` | `--cffy-ease-emphasized` / `--cffy-duration-300` | Background, border and ring transitions |
| `--cffy-input-label-font-size` / `--cffy-input-label-font-weight` | `--cffy-fs-3xs` / `600` | Field label |
| `--cffy-input-label-gap` | `--cffy-space-8` | Space between the label and the field |
| `--cffy-form-group-spacing` | `--cffy-space-14` | Space below each field group |

### Range CSS variables

`UiInputRange` (`.form-range`) reads these. The `sm` size keeps its own track and thumb size.

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-range-track-color` / `--cffy-input-range-fill-color` | `--cffy-surface-container-high` / primary tint | Empty track, and the filled track and thumb |
| `--cffy-input-range-track-size` / `--cffy-input-range-radius` | `0.75rem` / `--cffy-radius-full` | Track thickness and corners (the thumb shares the radius) |
| `--cffy-input-range-thumb-height` / `--cffy-input-range-thumb-width` | `1.95rem` / `0.3rem` | Thumb size (it narrows while focused) |
| `--cffy-input-range-thumb-ring-color` | `--cffy-surface-body-pane` | Ring that separates the thumb from the track |
| `--cffy-input-range-easing` / `--cffy-input-range-duration` | `--cffy-ease-decelerate` / `--cffy-duration-100` | Thumb width transition |

### File dropbox CSS variables

`UiInputFile` (`.input-file-dropbox`) reads these. The large dropbox keeps its own height, and a selected file its success colors. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-file-bg-color` / `--cffy-input-file-color` | `--cffy-surface-body-pane` / `--cffy-on-background` | Background, and the icon and text |
| `--cffy-input-file-border-width` / `--cffy-input-file-border-color` | `--cffy-border-width-md` / `--cffy-outline-text-field` | Dashed border |
| `--cffy-input-file-radius` / `--cffy-input-file-height` | `--cffy-radius-md` / `5rem` | Corners and height |
| `--cffy-input-file-font-size` | `--cffy-fs-3xs` | Text size |
| `--cffy-input-file-easing` / `--cffy-input-file-duration` | `--cffy-ease-decelerate` / `--cffy-duration-100` | State transitions |

### Checkbox, switch and radio CSS variables

`UiInputCheck` and `UiInputRadio` (`.form-check`) read these. Switches follow `--cffy-input-check-checked-color` unless `--cffy-input-switch-checked-color` is set. The `sm` and `lg` sizes keep their own box size and gap, and the danger checkbox its color.

```css
:root {
  --cffy-input-check-checked-color: var(--cffy-accent-a10);
  --cffy-input-check-radius: var(--cffy-radius-sm);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-check-size` | `1.25rem` | Box and radio size (switches are twice as wide) |
| `--cffy-input-check-gap` / `--cffy-input-check-spacing` | `--cffy-space-12` / `--cffy-space-14` | Space between the box and its label, and below each option |
| `--cffy-input-check-bg-color` / `--cffy-input-check-border-color` | `transparent` / `--cffy-outline-text-field` | Unchecked box |
| `--cffy-input-check-border-width` | `--cffy-border-width-md` | Box, radio and switch border |
| `--cffy-input-check-checked-color` | `--cffy-primary-a10` | Checked box, radio and switch |
| `--cffy-input-check-radius` | `4px` | Checkbox corners |
| `--cffy-input-check-easing` / `--cffy-input-check-duration` | `--cffy-ease-emphasized` / `--cffy-duration-300` | State transitions |
| `--cffy-input-switch-bg-color` / `--cffy-input-switch-border-color` | `--cffy-surface-container` / `--cffy-outline-surface` | Switch track when off |
| `--cffy-input-switch-thumb-color` / `--cffy-input-switch-checked-thumb-color` | `--cffy-muted-base` / `--cffy-surface-container-highest` | Switch thumb, off and on |
| `--cffy-input-switch-checked-color` | `--cffy-input-check-checked-color` | Switch track when on |

### Prefix and suffix CSS variables

The `prefix` and `suffix` adornments (`.input-group-prefix`, `.input-group-suffix`) follow the field's `--cffy-input-radius`, `--cffy-input-border-width`, `--cffy-input-border-color` and `--cffy-input-bg-color`, so they stay joined to it. These override the rest:

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-group-bg-color` | `--cffy-input-bg-color` | Adornment background |
| `--cffy-input-group-color` | `--cffy-muted-a10` | Adornment text and icon |
| `--cffy-input-group-padding-inline` | `0.5rem` | Adornment padding |
| `--cffy-input-group-font-size` / `--cffy-input-group-icon-size` | `--cffy-fs-2xs` / `--cffy-fs-base` | Adornment text and icon size |

### OTP CSS variables

`UiInputOtp` (`.form-otp`) boxes are square text fields: they take their size from `--cffy-input-height` and their surface, border and focus from the other `--cffy-input-*` variables. These set the rest:

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-input-otp-gap` | `0.5rem` | Space between boxes |
| `--cffy-input-otp-font-size` / `--cffy-input-otp-font-weight` | `--cffy-fs-base` / `--cffy-fw-500` | Digit text |
