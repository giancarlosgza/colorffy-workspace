All Colorffy form inputs share a common base — `label`, `placeholder`, `disabled`, `required`, `readonly`, `errorMessages`, `variant`, `size`, `hideLabel` — and bind with `v-model`.

## Text and textarea

```vue
<script setup lang="ts">
import { ref } from 'vue'

const name = ref('')
const bio = ref('')
</script>

<template>
  <UiInputText v-model="name" label="Name" placeholder="Jane Doe" required />
  <UiInputTextarea v-model="bio" label="Bio" :rows="4" />
</template>
```

## Select

`options` accepts an array; map labels / values with `optionLabel` / `optionValue`:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const role = ref(null)
const options = [
  { name: 'Admin', value: 'admin' },
  { name: 'User', value: 'user' },
]
</script>

<template>
  <UiInputSelect
    v-model="role"
    :options="options"
    option-label="name"
    option-value="value"
    label="Role"
  />
</template>
```

## Checkbox, switch, and radio

```vue
<template>
  <UiInputCheck v-model="agree" label="I agree to the terms" required />
  <UiInputCheck v-model="dark" label="Dark mode" variant="switch" />
  <UiInputRadio v-model="plan" :options="plans" option-label="name" option-value="id" inline />
</template>
```

## Range, file, color, and phone

`UiInputFile`, `UiInputColorPicker`, and `UiInputCheck` share the same base props as the other inputs (`errorMessages`, `disabled`, `required`, `optionalLabel`, `hideLabel`) and bind with `v-model` like the rest:

```vue
<template>
  <UiInputRange v-model="volume" :min="0" :max="100" :step="5" label="Volume" />
  <UiInputFile v-model="file" label="Upload" input-label="Choose a file" :error-messages="fileErrors" />
  <UiInputPhoneNumber v-model="phone" label="Phone" />
  <UiInputColorPicker v-model="color" label="Brand color" :maxlength="7" />
</template>
```

## OTP Input

`UiInputOtp` renders one box per character of a segmented PIN or verification code. It auto-advances focus as boxes fill, supports Backspace/Arrow key navigation, and distributes pasted (or autofilled) codes across boxes. `modelValue` is always a plain string; `length` (default `6`) controls the number of boxes.

```vue
<script setup lang="ts">
import { ref } from 'vue'

const code = ref('')

function handleComplete(value: string) {
  console.log('Code complete:', value)
}
</script>

<template>
  <UiInputOtp v-model="code" label="Verification code" @complete="handleComplete" />
  <UiInputOtp v-model="pin" label="4-digit PIN" :length="4" />
</template>
```

**Props:** `length` (default `6`), `integerOnly` (default `true` — numeric `inputmode`, non-digit characters discarded on input/paste; set to `false` for alphanumeric codes), `autofocus`, plus the shared base props (`errorMessages`, `disabled`, `required`, `readonly`, `variant`, `size`, `rounded`, `hideLabel`).

**Events:** `update:modelValue`, `onUpdate`, and `complete` — fired once with the full value when every box is filled.

## Prefix and suffix

`UiInputText` exposes `#prefix` and `#suffix` named slots. Content rendered in either slot gets a bordered box attached to the input — useful for icons or units.

```vue
<template>
  <UiInputText v-model="search" label="Search">
    <template #prefix>
      <UiIconMaterial icon-code="&#xe8b6;" />
    </template>
  </UiInputText>

  <UiInputText v-model="price" label="Price" type="number">
    <template #prefix>
      $
    </template>
    <template #suffix>
      USD
    </template>
  </UiInputText>
</template>
```

## Shared base props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string \| null` | — | Field label. |
| `placeholder` | `string \| null` | — | Placeholder text. |
| `errorMessages` | `string[]` | — | Validation messages shown below the field. |
| `variant` | `'filled' \| 'outline' \| 'transparent' \| null` | — | Visual style. |
| `size` | `'sm' \| 'lg' \| null` | — | Field size. |
| `disabled` / `required` / `readonly` / `rounded` | `boolean` | `false` | Field states. |
| `hideLabel` | `boolean` | `false` | Visually hide the label. |

## Per-input highlights

| Component | Notable props | `v-model` type |
|-----------|---------------|----------------|
| `UiInputText` | `type`, `maxlength`, `min`, `max`, `autofocus` | `string \| number \| null` |
| `UiInputTextarea` | `rows`, `cols`, `resize` | `string \| null` |
| `UiInputSelect` | `options`, `optionLabel`, `optionValue` | `string \| number \| object \| null` |
| `UiInputRadio` | `options`, `optionLabel`, `optionValue`, `inline` | `string \| number \| null` |
| `UiInputRange` | `min`, `max`, `step` | `string \| number \| null` |
| `UiInputCheck` | `variant: 'switch'`, `label` (required) | `string \| boolean \| null` |
| `UiInputFile` | `inputLabel`, `size: 'lg'` (taller dropbox) | `File \| null` |
| `UiInputColorPicker` | `maxlength` | `string \| null` |
| `UiInputPhoneNumber` | `maxlength`, `autofocus` | `string \| null` |
| `UiInputOtp` | `length`, `integerOnly`, `autofocus` | `string` |

::note
Most inputs emit both `update:modelValue` (for `v-model`) and an `onUpdate` convenience event with the same payload — this now includes `UiInputCheck`.
::

::note
**Breaking change:** `UiInputColorPicker`'s length-limit prop was renamed from `maxLength` to `maxlength` (lowercase, matching the other text inputs).
::

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the fields inside it. They style text inputs, textareas and selects, and the color picker's field reads the same surface, border, radius and focus variables. The outline, rounded, transparent, `sm` and `lg` styles keep their own values, and disabled fields keep their muted look.

```css
:root {
  --input-radius: var(--radius-full);
  --input-padding-inline: var(--space-14);
  --input-focus-border-color: var(--theme-accent-a10);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--input-height` | `2.5rem` | Field height |
| `--input-padding-inline` / `--input-padding-block` | `--space-8` / `--space-4` | Field padding |
| `--input-radius` | `$form-border-radius` (8px) | Corners |
| `--input-bg-color` / `--input-color` | `transparent` / `--theme-on-background` | Background and text |
| `--input-border-width` / `--input-border-color` | `1px` / `--theme-outline-text-field` | Border |
| `--input-font-size` | `0.875rem` | Text size |
| `--input-shadow` | `--shadow-xs` | Resting shadow |
| `--input-placeholder-color` | `--theme-muted-a10` at 65% | Placeholder text |
| `--input-filled-bg-color` | `--theme-surface-container-high` | Background of `.form-filled` fields |
| `--input-hover-border-color` | `--theme-on-background` | Hovered border |
| `--input-focus-bg-color` / `--input-focus-border-color` | `--theme-surface-container-high` / `--theme-primary-a10` | Focused field |
| `--input-focus-ring-color` | `--theme-primary-base-fixed` at 25% | Focus ring |
| `--input-invalid-color` / `--input-invalid-ring-color` | `--theme-danger-a10` / `--theme-danger-base-fixed` at 25% | Invalid border and message, and its focus ring |
| `--input-easing` / `--input-duration` | `--ease-emphasized` / `--duration-300` | Background, border and ring transitions |
| `--input-label-font-size` / `--input-label-font-weight` | `--fs-3xs` / `600` | Field label |
| `--input-label-gap` | `--space-8` | Space between the label and the field |
| `--form-group-spacing` | `--space-14` | Space below each field group |

### Range CSS variables

`UiInputRange` (`.form-range`) reads these.

| Variable | Default | Controls |
|----------|---------|----------|
| `--input-range-track-color` / `--input-range-fill-color` | `--theme-surface-container-high` / primary tint | Empty track, and the filled track and thumb |
| `--input-range-track-size` / `--input-range-radius` | `0.75rem` / `--radius-full` | Track thickness and corners (the thumb shares the radius) |
| `--input-range-thumb-height` / `--input-range-thumb-width` | `1.95rem` / `0.3rem` | Thumb size (it narrows while focused) |
| `--input-range-thumb-ring-color` | `--theme-surface-body-pane` | Ring that separates the thumb from the track |
| `--input-range-easing` / `--input-range-duration` | `--ease-decelerate` / `--duration-100` | Thumb width transition |

### File dropbox CSS variables

`UiInputFile` (`.input-file-dropbox`) reads these. The large dropbox keeps its own height, and a selected file its success colors.

| Variable | Default | Controls |
|----------|---------|----------|
| `--input-file-bg-color` / `--input-file-color` | `--theme-surface-body-pane` / `--theme-on-background` | Background, and the icon and text |
| `--input-file-border-width` / `--input-file-border-color` | `--border-width-md` / `--theme-outline-text-field` | Dashed border |
| `--input-file-radius` / `--input-file-height` | `--radius-md` / `5rem` | Corners and height |
| `--input-file-font-size` | `--fs-3xs` | Text size |
| `--input-file-hover-bg-color` / `--input-file-pressed-bg-color` | `--theme-surface-container-high` / `--theme-surface-container-highest` | Hovered and pressed dropbox |
| `--input-file-easing` / `--input-file-duration` | `--ease-decelerate` / `--duration-100` | State transitions |

### Checkbox, switch and radio CSS variables

`UiInputCheck` and `UiInputRadio` (`.form-check`) read these. Switches follow `--input-check-checked-color` unless `--input-switch-checked-color` is set. The `sm` and `lg` sizes keep their own box size and gap, and the danger checkbox its color.

```css
:root {
  --input-check-checked-color: var(--theme-accent-a10);
  --input-check-radius: var(--radius-sm);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--input-check-size` | `1.25rem` | Box and radio size (switches are twice as wide) |
| `--input-check-gap` / `--input-check-spacing` | `--space-12` / `--space-14` | Space between the box and its label, and below each option |
| `--input-check-bg-color` / `--input-check-border-color` | `transparent` / `--theme-outline-text-field` | Unchecked box |
| `--input-check-border-width` | `--border-width-md` | Box, radio and switch border |
| `--input-check-checked-color` | `--theme-primary-a10` | Checked box, radio and switch |
| `--input-check-radius` | `4px` | Checkbox corners |
| `--input-check-easing` / `--input-check-duration` | `--ease-emphasized` / `--duration-300` | State transitions |
| `--input-switch-bg-color` / `--input-switch-border-color` | `--theme-surface-container` / `--theme-outline-surface` | Switch track when off |
| `--input-switch-thumb-color` / `--input-switch-checked-thumb-color` | `--theme-muted-base` / `--theme-surface-container-highest` | Switch thumb, off and on |
| `--input-switch-checked-color` | `--input-check-checked-color` | Switch track when on |
