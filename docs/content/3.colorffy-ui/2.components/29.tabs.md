`UiTabs` renders a keyboard-accessible tab list (arrow keys, Home/End). Pass an array of tab items and react to selection with `updateActiveTab`.

## Add tabs

```vue
<script setup lang="ts">
import type { ITabItem } from '@colorffy/ui'
import { ref } from 'vue'

const tabs: ITabItem[] = [
  { id: 'overview', label: 'Overview' },
  { id: 'pricing', label: 'Pricing' },
  { id: 'faq', label: 'FAQ', disabled: true },
]
const active = ref('overview')
</script>

<template>
  <UiTabs :tabs="tabs" :active-tab="active" @update-active-tab="active = $event" />

  <section v-show="active === 'overview'">Overview panel</section>
  <section v-show="active === 'pricing'">Pricing panel</section>
</template>
```

## Add a badge to a tab

Each tab item accepts an optional `badge` (a `Partial<IBadgeProps>`) rendered after the label — handy for counts or status hints.

```vue
<script setup lang="ts">
const tabs: ITabItem[] = [
  { id: 'inbox', label: 'Inbox', badge: { text: '12', variant: 'primary', pill: true } },
  { id: 'archived', label: 'Archived', badge: { text: 'New', variant: 'success' } },
  { id: 'spam', label: 'Spam' },
]
</script>
```

## Style as pills or contrast

```vue
<template>
  <UiTabs :tabs="tabs" pill-tabs />
  <UiTabs :tabs="tabs" contrast-tabs />
</template>
```

## Add a leading icon to a tab

Each tab item accepts an optional `icon` (a Material Symbols entity code, same convention as `INavItem.icon`) rendered before the label.

```vue
<script setup lang="ts">
const tabs: ITabItem[] = [
  { id: 'overview', label: 'Overview', icon: '&#xe88a;' },
  { id: 'details', label: 'Details', icon: '&#xe873;' },
]
</script>
```

## Icon-only tabs

Set `iconOnly` to show only the icon of tabs that have one, as square buttons. The label stays the tab's accessible name (visually hidden) and shows as a native tooltip on hover. Tabs without an `icon` keep their label, and badges still render.

```vue
<template>
  <UiTabs :tabs="tabs" pill-tabs rounded icon-only />
</template>
```

## Fluid (equal-width) tabs

Set `fluid` to stretch every tab to fill the available width equally.

```vue
<template>
  <UiTabs :tabs="tabs" fluid />
</template>
```

## Small tabs

Set `size="sm"` to render the tab buttons at the default button height and font size instead of the larger tab defaults.

```vue
<template>
  <UiTabs :tabs="tabs" pill-tabs size="sm" />
</template>
```

## Fit and rounded pill tabs

By default the tab bar spans its container. Set `fit` to make it only as wide as its tabs, and `rounded` to make pill tabs and their indicator fully rounded. `rounded` only applies together with `pillTabs`, and `fit` is ignored when `fluid` is set.

```vue
<template>
  <UiTabs :tabs="tabs" pill-tabs fit rounded />
</template>
```

## Overflow scrolling

When the tab list is wider than its container, it scrolls horizontally with a thin scrollbar instead of wrapping or clipping. No extra prop is needed — this is the default behavior of `UiTabs`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tabs` | `ITabItem[]` | — | Tab items: `{ id, label, disabled?, panelId?, badge?, icon? }`. |
| `activeTab` | `string` | first tab | Id of the active tab. |
| `pillTabs` | `boolean` | `false` | Pill styling. |
| `contrastTabs` | `boolean` | `false` | Contrast styling. |
| `fluid` | `boolean` | `false` | Equal-width tabs that stretch to fill the available space. |
| `fit` | `boolean` | `false` | The tab bar is only as wide as its tabs. Ignored when `fluid` is set. |
| `rounded` | `boolean` | `false` | Fully rounded pill tabs and indicator. Requires `pillTabs`. |
| `iconOnly` | `boolean` | `false` | Tabs with an `icon` show only the icon; the label becomes the accessible name and a hover tooltip. |
| `size` | `'sm' \| 'md' \| null` | `null` | `'sm'` uses the default button height and font size. `'md'`/`null` keep the larger tab size. |

**Emits:** `updateActiveTab(tabId: string)`.

::note
The active indicator (the underline, or the raised pill with `pillTabs`) is positioned *and* animated entirely in CSS with anchor positioning — no JavaScript is involved, and the slide is skipped under `prefers-reduced-motion: reduce`. Where anchor positioning is unsupported, the active tab falls back to its own bottom border — or to a filled, shadowed background for `pillTabs` — so nothing is lost. The slide covers up to 16 tabs; past that the indicator still lands correctly, it just jumps.
::

::tip
For a compact segmented switch, use `UiSegmentedControls` with `ISegmentedTab` items (`{ id, label, position }`).
::

## CSS variables

Set these on `:root`, or on any wrapper to restyle only the tabs inside it. The `--tabs-pills-*` variables only affect `pillTabs`; `contrastTabs` and `rounded` keep their own background and radius. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

```css
:root {
  --tabs-indicator-color: var(--theme-accent-a10);
  --tabs-link-active-color: var(--theme-primary-a10);
  --tabs-pills-bg-color: var(--theme-surface-container);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--tabs-gap` | `--space-8` | Space between tabs |
| `--tabs-border-color` | `--theme-outline-button` | Bottom border of underline tabs |
| `--tabs-indicator-color` / `--tabs-indicator-size` | `--theme-primary-a10` / `3px` | Underline indicator |
| `--tabs-easing` / `--tabs-duration` | `--ease-decelerate` / `--duration-300` | Indicator slide |
| `--tabs-link-color` / `--tabs-link-font-weight` | `--theme-muted-a10` / `--fw-500` | Tab text |
| `--tabs-link-hover-color` | `--theme-on-background` | Hovered tab text |
| `--tabs-link-active-color` | `--theme-on-background` | Active tab text |
| `--tabs-pills-bg-color` | `--theme-surface-container-low` | Pill tabs container |
| `--tabs-pills-radius` | `--radius-lg` | Pill and indicator corners (the container follows) |
| `--tabs-pills-indicator-bg-color` / `--tabs-pills-indicator-shadow` | `--theme-surface-body-pane` / `--shadow-md` | Raised pill behind the active tab |
