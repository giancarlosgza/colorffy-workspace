`UiDatatable` renders rows from an `items` array against an explicit `columns` definition. Each column's `key` is the data field, the sort key, and the `cell-<key>` slot name; `label` is the header text.

## Add a datatable

```vue
<script setup lang="ts">
import type { IDatatableColumn } from '@colorffy/ui'

const columns: IDatatableColumn[] = [
  { key: 'name', label: 'Name' },
  { key: 'email', label: 'Email' },
  { key: 'total', label: 'Total', align: 'end' },
]

const items = [
  { name: 'John Doe', email: 'john@example.com', total: 1280 },
  { name: 'Jane Smith', email: 'jane@example.com', total: 940 },
]
</script>

<template>
  <UiDatatable
    :columns="columns"
    :items="items"
    default-sort-key="name"
    table-class="table-bordered"
  />
</template>
```

## Customize a cell

The cell slot name is `cell-<key>`:

```vue
<template>
  <UiDatatable :columns="columns" :items="items">
    <template #cell-total="{ item }">
      <strong>${{ item.total }}</strong>
    </template>
  </UiDatatable>
</template>
```

## Hide, align, and manage columns

Mark a column `hidden` to start it collapsed, then enable `column-manager` so users can toggle it:

```vue
<script setup lang="ts">
import type { IDatatableColumn } from '@colorffy/ui'

const columns: IDatatableColumn[] = [
  { key: 'id', label: 'ID', hidden: true },
  { key: 'name', label: 'Name' },
  { key: 'actions', label: 'Actions', sortable: false, align: 'end' },
]
</script>

<template>
  <UiDatatable :columns="columns" :items="items" column-manager>
    <template #cell-actions="{ item }">
      <UiButton variant="outline" size="sm" :text="`Edit ${item.name}`" />
    </template>
  </UiDatatable>
</template>
```

## Customize the toolbar

The toolbar above the table has two sides. `#controls` fills the left side (search, filters, bulk actions). On the right, `#actions-start` and `#actions-end` add your own buttons to the same button group as the built-in column buttons, before and after them. The toolbar renders as soon as any of these slots is used, even without `column-manager`.

```vue
<template>
  <UiDatatable :columns="columns" :items="items" column-manager>
    <template #controls>
      <UiInputText v-model="search" placeholder="Search" hide-label />
    </template>
    <template #actions-start>
      <UiButtonTooltip
        id="export"
        variant="outline"
        size="sm"
        icon
        icon-variant="shape-sm"
        tooltip-text="Export CSV"
      >
        <template #icon>
          <UiIconMaterial icon-code="&#xf090;" />
        </template>
      </UiButtonTooltip>
    </template>
  </UiDatatable>
</template>
```

To restyle the built-in buttons, pass `toolbarButton`. Its `variant`, `color`, `size`, `customClass` and `rounded` override the default outline, small style on both the column toggle and the column manager:

```vue
<template>
  <UiDatatable
    :columns="columns"
    :items="items"
    column-manager
    :toolbar-button="{ variant: 'tonal', size: 'md' }"
  />
</template>
```

To replace a built-in button entirely, use the `#column-toggle` or `#column-manager` scoped slot. Both receive the column state (`IDatatableColumnSlotProps`), so your markup drives the same visibility logic:

| Slot prop | Type | Description |
|-----------|------|-------------|
| `columns` | `IDatatableColumn[]` | Every column, including hidden ones. |
| `allVisible` | `boolean` | True when no column is hidden. |
| `isVisible` | `(key: string) => boolean` | Whether a column is shown. |
| `isLocked` | `(key: string) => boolean` | True for the last visible column, which cannot be hidden. |
| `toggle` | `(key: string) => void` | Show or hide one column. |
| `toggleAll` | `() => void` | Show every column, or restore the default hidden ones. |

```vue
<template>
  <UiDatatable :columns="columns" :items="items" column-manager>
    <template #column-manager="{ columns, isVisible, isLocked, toggle }">
      <UiChip
        v-for="column in columns"
        :key="column.key"
        :text="column.label"
        :selected="isVisible(column.key)"
        :disabled="isLocked(column.key)"
        @click="toggle(column.key)"
      />
    </template>
  </UiDatatable>
</template>
```

## Select rows

Set `selectable` and bind `v-model:selected` to an array of row identities. A row's identity is the same value used for its `:key` — `rowKey` if set, else the row's `id`, else its array index (see [Props](#props)). The header checkbox selects/clears every currently sorted row and shows an indeterminate state when only some are selected; selection stays attached to the row across sorting as long as rows have a stable `id` (or `rowKey`).

```vue
<script setup lang="ts">
import { ref } from 'vue'

const selected = ref<(string | number)[]>([])
</script>

<template>
  <UiDatatable
    :columns="columns"
    :items="items"
    selectable
    v-model:selected="selected"
  />
</template>
```

## Stick the header while scrolling

Set `stickyHeader` to keep the header visible while the body scrolls. It automatically wraps the table in a bounded, vertically-scrollable container (`.table-responsive-sticky`); set its max height with `stickyHeight` (default `32rem`). It takes any CSS length; a number is read as pixels:

```vue
<template>
  <UiDatatable
    :columns="columns"
    :items="items"
    sticky-header
    sticky-height="20rem"
  />
</template>
```

## Show loading and empty states

```vue
<template>
  <!-- Skeleton rows while data loads -->
  <UiDatatable :columns="columns" :items="[]" :is-loading="true" :skeleton-rows="6" />

  <!-- Built-in empty state -->
  <UiDatatable
    :columns="columns"
    :items="[]"
    empty-state-title="No customers yet"
    empty-state-subtitle="New customers will appear here."
  />
</template>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `columns` | `IDatatableColumn[]` | — | Column definitions (required). |
| `items` | `Record<string, any>[]` | — | Row data (required). |
| `rowKey` | `string` | `id` → index | Stable key field for rows; also the row-selection identity. |
| `selectable` | `boolean` | `false` | Show a leading checkbox column. Pair with `v-model:selected`. |
| `selected` | `(string \| number)[]` | `[]` | Selected row identities. Bind with `v-model:selected`. |
| `stickyHeader` | `boolean` | `false` | Stick the header while the body scrolls (wraps in `.table-responsive-sticky`). |
| `stickyHeight` | `string \| number \| null` | `null` (`32rem`) | Max height of the sticky scroll container. Numbers are pixels. |
| `sortable` | `boolean` | `true` | Enable sorting (per-column opt-out via `column.sortable`). |
| `defaultSortKey` | `string` | `''` | Column `key` to sort by initially. |
| `defaultSortOrder` | `'asc' \| 'desc'` | `'asc'` | Initial sort direction. |
| `columnManager` | `boolean` | `false` | Show the icon-only show / hide column menu. |
| `columnManagerTooltip` | `string` | `'Manage columns'` | Tooltip and accessible name of the column manager button. |
| `toolbarButton` | `DatatableToolbarButton \| null` | `null` | `variant`, `color`, `size`, `customClass`, `rounded` for the built-in toolbar buttons. |
| `tableClass` | `'table-bordered' \| 'table-striped' \| 'table-borderless' \| string` | `''` | Table style. |
| `isLoading` | `boolean` | `false` | Show skeleton rows. |
| `skeletonRows` / `skeletonCols` | `number` | `10` / `5` | Skeleton dimensions. |
| `caption` | `string` | — | Accessible `<caption>`. |
| `emptyStateTitle` | `string` | `'No data available'` | Empty-state title. |
| `emptyStateSubtitle` | `string` | … | Empty-state subtitle. |

**Column (`IDatatableColumn`):** `key`, `label`, `sortable?`, `hidden?`, `align?` (`start` / `center` / `end`), `thClass?`, `tdClass?`.
**Slots:** `cell-<key>` per column; `controls`, `actions-start`, `actions-end`; `column-toggle` and `column-manager` (scoped, `IDatatableColumnSlotProps`).

## CSS variables

These style the `.table` the datatable renders, and any plain `.table`. Set them on `:root`, or on any wrapper to restyle only the tables inside it. The `sm` and `lg` sizes keep their own cell padding, and the bordered and borderless styles their own corners (bordered also its header background). The `stickyHeight` prop wins over `--cffy-table-sticky-max-height`. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

```css
:root {
  --cffy-table-header-bg-color: var(--cffy-surface-container);
  --cffy-table-radius: var(--cffy-radius-md);
  --cffy-table-cell-padding-block: var(--cffy-space-12);
}
```

| Variable | Default | Controls |
|----------|---------|----------|
| `--cffy-table-bg-color` / `--cffy-table-color` | `transparent` / `currentColor` | Table background and text |
| `--cffy-table-border-color` / `--cffy-table-border-width` | `--cffy-outline-surface` / `--cffy-border-width-sm` | Row and cell borders |
| `--cffy-table-cell-padding-inline` / `--cffy-table-cell-padding-block` | `--cffy-space-8` / `--cffy-space-8` | Cell padding (header cells use 1.5× the block padding) |
| `--cffy-table-font-size` | `0.75rem` | Body text |
| `--cffy-table-radius` | `--cffy-radius-none` | Header corners |
| `--cffy-table-header-bg-color` / `--cffy-table-header-color` | `--cffy-surface-a10` / `--cffy-muted-a10` | Header background and text |
| `--cffy-table-header-font-size` / `--cffy-table-header-font-weight` | `--cffy-fs-4xs` / `--cffy-fw-600` | Header text |
| `--cffy-table-icon-color` / `--cffy-table-icon-size` | `--cffy-muted-a10` / `1.25rem` | Icons in `.td-name` cells |
| `--cffy-table-selected-bg-color` | `--cffy-surface-a0` | Selected rows |
| `--cffy-table-striped-bg-color` | `--cffy-surface-container` | Odd rows of `.table-striped` |
| `--cffy-table-easing` / `--cffy-table-duration` | `ease-in-out` / `--cffy-duration-100` | Row hover transition |
| `--cffy-table-sticky-max-height` | `32rem` | Height of the scroll area with `stickyHeader` |
| `--cffy-table-sticky-column-bg-color` | `--cffy-surface-body-pane` | Pinned `.highlight` column while scrolled in `.table-scrollable` |
