A detail page shows a single record, reached from a collection by its id: a project, a customer, an order. Use it when the record has more than one kind of content (summary, related items, files, history) and the user needs to act on it without leaving the page.

![Orbit's project page: breadcrumb, project header with Share and Status actions, a row of status, dates and team avatars, and the Overview tab with progress, budget, milestones and notes](/recipes/detail-page.jpg)

## Anatomy

1. **Breadcrumb**: [UiBreadcrumb](/colorffy-ui/components/breadcrumb) back to the collection, ending on the record's name.
2. **Header**: an icon tile in the record's color next to [UiHeaderContent](/colorffy-ui/components/layout) `size="md"`, with the record key as headline and the actions in a [UiButtonGroup](/colorffy-ui/components/button-group): share ([UiButtonTooltip](/colorffy-ui/components/button)) and status ([UiButtonMenu](/colorffy-ui/components/button-menu)).
3. **Properties**: status and priority as [UiBadge](/colorffy-ui/components/badge), the date range as a caption, and the team as a [UiAvatarGroup](/colorffy-ui/components/avatar) inside a [UiTooltip](/colorffy-ui/components/tooltip).
4. **Tabs**: [UiTabs](/colorffy-ui/components/tabs) with an icon and an optional count badge per tab, each tab wired to a `<section role="tabpanel">`.
5. **Overview panel**: progress and budget cards ([UiCard](/colorffy-ui/components/card), [UiProgressBar](/colorffy-ui/components/progress)), milestones in a [UiTimeline](/colorffy-ui/components/timeline), and notes in a [UiAccordionGroup](/colorffy-ui/components/accordion).
6. **Tasks panel**: tasks grouped by status in [UiListGroup](/colorffy-ui/components/list), each with a [UiInputCheck](/colorffy-ui/components/inputs#checkbox-switch-and-radio), and [UiEmpty](/colorffy-ui/components/empty) when there are none.
7. **Files panel**: a [UiInputFile](/colorffy-ui/components/inputs#range-file-color-and-phone) dropbox above the list of files.
8. **Activity panel**: the record's history in a [UiTimeline](/colorffy-ui/components/timeline).
9. **Not found**: a [UiEmpty](/colorffy-ui/components/empty) with a way back when the id matches nothing.

## Page skeleton

```vue [pages/projects/[id].vue]
<script setup lang="ts">
import type { IAvatarProps, ITabItem, ITimelineItem, ThemeColor } from '@colorffy/ui'
import { NuxtLink } from '#components'

definePageMeta({ pageTitle: 'Project' })

/** Data */
const statuses: { id: string, label: string, color: ThemeColor, icon: string }[] = [
  { id: 'on-track', label: 'On track', color: 'success', icon: '&#xe86c;' },
  { id: 'at-risk', label: 'At risk', color: 'warning', icon: '&#xe002;' }
]
const projects = [{ id: 'mobile-app-v2', name: 'Mobile app v2', key: 'MOB', lead: 'Maya Chen', icon: '&#xe325;', dates: 'Aug 4 → Nov 28' }]
const metrics = [
  { title: 'Progress', value: '68%', percent: 68 },
  { title: 'Budget', value: '$41,200', percent: 86, alert: '86% spent with 32% of the work left.' }
]
const team: IAvatarProps[] = [{ initials: 'MC', alt: 'Maya Chen', color: 'primary' }, { initials: 'LM', alt: 'Leo Martins', color: 'accent' }]
const milestones: ITimelineItem[] = [
  { id: 'kickoff', time: 'Aug 4', title: 'Kickoff', text: 'Done', icon: '&#xe5ca;', variant: 'success' },
  { id: 'beta', time: 'Oct 12', title: 'Beta', text: 'At risk · 68% of tasks done', icon: '&#xe153;', variant: 'warning' }
]
const activity: ITimelineItem[] = [{ id: 'created', time: 'Aug 4', title: 'Maya Chen created Mobile app v2', icon: '&#xe145;' }]
const tasks = ref([
  { id: 't8', title: 'Offline sync for the task list', meta: 'Leo Martins · Due Oct 10', done: false },
  { id: 't12', title: 'App Store screenshots', meta: 'Maya Chen · Due Oct 20', done: true }
])
const files = ref([{ id: 'f2', name: 'Offline sync spec.pdf', meta: '1.4 MB · Leo Martins · Yesterday' }])
const activeTab = ref('overview')
const statusId = ref('at-risk')
const briefOpen = ref(true)
const pendingFile = ref<File | null>(null)

/** Composables */
const route = useRoute()

/** Computed */
const project = computed(() => projects.find(item => item.id === route.params.id))
const status = computed(() => statuses.find(item => item.id === statusId.value) ?? statuses[0]!)
const openTasks = computed(() => tasks.value.filter(task => !task.done))
const taskGroups = computed(() => [
  { label: 'Open', variant: 'tonal tonal-info', items: openTasks.value },
  { label: 'Done', variant: 'tonal tonal-success', items: tasks.value.filter(task => task.done) }
].filter(group => group.items.length))
const tabs = computed<ITabItem[]>(() => [
  { id: 'overview', label: 'Overview', icon: '&#xe9b0;', panelId: 'project-panel-overview' },
  { id: 'tasks', label: 'Tasks', icon: '&#xe2e6;', panelId: 'project-panel-tasks',
    badge: openTasks.value.length ? { text: String(openTasks.value.length), variant: 'tonal tonal-primary', pill: true } : null },
  { id: 'files', label: 'Files', icon: '&#xe2c7;', panelId: 'project-panel-files' },
  { id: 'activity', label: 'Activity', icon: '&#xe889;', panelId: 'project-panel-activity' }
])

/** Methods */
function upload(file: File | null) {
  if (file)
    files.value.unshift({ id: `upload-${Date.now()}`, name: file.name, meta: 'Just now' })
  pendingFile.value = null
}

/** Watchers */
watch(() => route.params.id, () => {
  activeTab.value = 'overview'
})
</script>

<template>
  <div class="container mt-3 mb-5">
    <template v-if="project">
      <!-- Breadcrumb -->
      <UiBreadcrumb
        :as="NuxtLink" :items="[{ label: 'Projects', to: '/projects', icon: '&#xe2c7;' }, { label: project.name }]"
        separator-icon="&#xe5cc;" :structured-data="false" class="mb-3"
      />

      <!-- Header -->
      <div class="d-flex align-items-start gap-3">
        <span class="d-inline-flex p-3 rounded-lg flex-shrink-0 bg-primary-container text-on-primary-container">
          <UiIconMaterial :icon-code="project.icon" class="fs-2xl lh-1" />
        </span>
        <UiHeaderContent :headline="`${project.key} · Led by ${project.lead}`" :title="project.name" size="md" class="flex-grow-1">
          <template #actions>
            <UiButtonMenu id="project-status" text="Status" variant="tonal" :color="status.color" size="sm" placement="bottom-end">
              <template #menu>
                <UiButtonMenuItem
                  v-for="item in statuses" :key="item.id" :item-text="item.label" :icon="item.icon"
                  :icon-class="`text-${item.color}`" :icon-trailing="item.id === statusId ? '&#xe5ca;' : null"
                  @click="statusId = item.id"
                />
              </template>
            </UiButtonMenu>
          </template>
        </UiHeaderContent>
      </div>

      <!-- Properties -->
      <div class="d-flex flex-wrap align-items-center gap-3 mb-4">
        <UiBadge :text="status.label" :variant="`tonal tonal-${status.color}`" :icon-code="status.icon" />
        <span class="caption text-muted">{{ project.dates }}</span>
        <UiTooltip :text="team.map(member => member.alt).join(', ')" placement="bottom">
          <UiAvatarGroup :avatars="team" :max="4" size="sm" />
        </UiTooltip>
      </div>

      <!-- Tabs -->
      <UiTabs v-model:active-tab="activeTab" :tabs="tabs" class="mb-4" />

      <!-- Overview -->
      <section v-show="activeTab === 'overview'" id="project-panel-overview" role="tabpanel" aria-labelledby="tab-overview">
        <div class="row">
          <div v-for="metric in metrics" :key="metric.title" class="col-12 col-md-6 mb-3">
            <UiCard :title="metric.title" custom-class="h-100" variant="pane">
              <template #body>
                <p class="fs-3xl fw-800 lh-1 tabular-numbers mb-3">{{ metric.value }}</p>
                <UiProgressBar :value="metric.percent" :aria-label="`${project.name} ${metric.title}`" />
                <div v-if="metric.alert" role="status" class="d-flex gap-2 p-3 mt-3 rounded-md bg-warning-container text-on-warning-container">
                  <UiIconMaterial icon-code="&#xe002;" class="fs-lg lh-1" />
                  <p class="mb-0">{{ metric.alert }}</p>
                </div>
              </template>
            </UiCard>
          </div>
          <div class="col-12 col-lg-7 mb-3">
            <UiCard title="Milestones" custom-class="h-100" variant="pane">
              <template #body>
                <UiTimeline :items="milestones" size="sm" />
              </template>
            </UiCard>
          </div>
          <div class="col-12 col-lg-5 mb-3">
            <UiAccordionGroup>
              <UiAccordion id="project-brief" v-model:open="briefOpen" name="project-notes" title="Brief" text="Offline sync and a faster onboarding." />
              <UiAccordion id="project-risks" name="project-notes" title="Risks · 1" text="Attachment sync waits on the new API." />
            </UiAccordionGroup>
          </div>
        </div>
      </section>

      <!-- Tasks -->
      <section v-show="activeTab === 'tasks'" id="project-panel-tasks" role="tabpanel" aria-labelledby="tab-tasks">
        <UiEmpty v-if="!taskGroups.length" title="No tasks yet" subtitle="Tasks you add to this project show up here." />
        <div v-for="group in taskGroups" :key="group.label" class="mb-4">
          <UiBadge :text="group.label" :variant="group.variant" size="sm" class="mb-2" />
          <UiListGroup>
            <UiListItem v-for="task in group.items" :key="task.id" :title="task.title" :text="task.meta" :custom-class="{ 'opacity-70': task.done }">
              <template #media>
                <UiInputCheck
                  :id="`task-${task.id}`" :model-value="task.done" :label="`Mark ${task.title} as done`" hide-label
                  @update:model-value="task.done = $event === true"
                />
              </template>
            </UiListItem>
          </UiListGroup>
        </div>
      </section>

      <!-- Files -->
      <section v-show="activeTab === 'files'" id="project-panel-files" role="tabpanel" aria-labelledby="tab-files">
        <UiInputFile
          id="project-upload" v-model="pendingFile" label="Upload a file" hide-label
          input-label="Drop a file here or click to browse" size="lg" class="mb-4" @update="upload"
        />
        <UiListGroup>
          <UiListItem
            v-for="file in files" :key="file.id" :title="file.name" :text="file.meta" icon="&#xe873;"
            custom-icon-wrapper-class="bg-info-container" custom-icon-class="text-on-info-container"
          />
        </UiListGroup>
      </section>

      <!-- Activity -->
      <section v-show="activeTab === 'activity'" id="project-panel-activity" role="tabpanel" aria-labelledby="tab-activity">
        <UiCard variant="pane">
          <template #body>
            <UiTimeline :items="activity" />
          </template>
        </UiCard>
      </section>
    </template>

    <!-- Unknown project -->
    <UiCard v-else variant="pane" class="mt-5">
      <template #body>
        <UiEmpty title="Project not found" subtitle="It may have been archived, or the link is missing a character." use-custom-icon icon-code="&#xe2c7;">
          <template #action>
            <UiButton :as="NuxtLink" to="/projects" text="Back to projects" variant="filled" color="primary" />
          </template>
        </UiEmpty>
      </template>
    </UiCard>
  </div>
</template>
```

## Header

The icon tile gives the record a recognizable mark: `p-3 rounded-lg` with the container pair of the record's color (`bg-<color>-container text-on-<color>-container`) and the icon at `fs-2xl lh-1`. `UiHeaderContent` takes `flex-grow-1` so its actions stay at the right edge. `size="md"` sets the title one step above the `sm` used by collection pages, and the `headline` carries the record key and owner, so the properties row doesn't need them.

`UiHeaderContent` renders the title as the page's `h1`. The skeleton keeps one action; a full header groups them in a `UiButtonGroup`. Share is a labelled `UiButtonTooltip`, and Status is a `UiButtonMenu` whose `color` follows the current status, with a chevron through `icon-trailing` and the `#icon` slot. In the menu, mark the current choice with a check in `icon-trailing` and color each item's icon with `icon-class="text-<color>"`, so the menu reads like the badge it changes:

```vue
<UiButtonGroup>
  <UiButtonTooltip text="Share" variant="outline" size="sm" tooltip-text="Copy a link to this project" @click="copyLink">
    <template #icon>
      <UiIconMaterial icon-code="&#xe157;" />
    </template>
  </UiButtonTooltip>
  <UiButtonMenu id="project-status" text="Status" variant="tonal" :color="status.color" size="sm" icon-trailing placement="bottom-end">
    <template #icon>
      <UiIconMaterial icon-code="&#xe5cf;" />
    </template>
    <template #menu>
      <UiButtonMenuText item-text="Set project status" />
      <!-- One UiButtonMenuItem per status -->
      <UiButtonMenuDivider />
      <UiButtonMenuItem item-text="View status history" icon="&#xe889;" @click="activeTab = 'activity'" />
    </template>
  </UiButtonMenu>
</UiButtonGroup>
```

Add a scheduler to the same group with a [date input](/colorffy-ui/components/inputs#date) in button mode. It keeps its `label` for screen readers and drops the field margin:

```vue
<UiInputDate
  id="project-review" v-model="reviewAt" trigger="button" label="Schedule review" hide-label
  placeholder="Schedule" :time-options="{ step: 30, start: '09:00', end: '17:00' }" :min="today"
  :disabled-dates="isWeekend" class="mb-0"
/>
```

## Properties row

Properties are facts the user scans, not controls: badges for status and priority, the date range as `caption text-muted` (add a leading icon with `d-inline-flex align-items-center gap-1`), and the team as avatars. The row is `d-flex flex-wrap align-items-center gap-3`, so it wraps on narrow screens instead of scrolling. The status badge and the Status menu read from the same value, so changing one updates both.

Pass the team to `UiAvatarGroup` as `IAvatarProps[]`: `src` and `alt` when the member has a photo, `initials` and `color` otherwise. `max` collapses the rest into a `+N` avatar, and the surrounding `UiTooltip` lists every name.

## Wire the tabs to their panels

`UiTabs` renders each tab button with the id `tab-<id>`, built from the item's `id`. Give every item a `panelId` and render a matching section:

```vue
<UiTabs v-model:active-tab="activeTab" :tabs="[{ id: 'files', label: 'Files', panelId: 'project-panel-files' }]" />

<section v-show="activeTab === 'files'" id="project-panel-files" role="tabpanel" aria-labelledby="tab-files">
  …
</section>
```

`panelId` becomes the tab's `aria-controls`, and the panel names itself after its tab with `aria-labelledby="tab-<id>"`. Since the button ids aren't scoped, keep tab ids unique on the page when it has more than one tablist.

Toggle the panels with `v-show`, not `v-if`: every panel stays in the DOM, so each `aria-controls` points at an element that exists, and a panel keeps its state (an open accordion, a file still in the dropbox) when the user switches away and back. Reset `activeTab` in a watcher on `route.params.id`, because Nuxt reuses the page component when the user moves from one record to another.

Counts go in the tab's `badge`: `{ text, variant: 'tonal tonal-primary', pill: true }` for open tasks, and `null` when there's nothing to count.

## Overview

The two metric cards share a shape: a value in `fs-3xl fw-800 lh-1 tabular-numbers`, a `UiProgressBar` with an `aria-label` that says what it measures, and supporting numbers as `caption text-muted`. Pass `bar-class="bg-warning"` once the budget passes a threshold, and `bg-success` on progress when the record is closed.

A condition that needs attention becomes a tinted callout under the bar, built from the container pair: `d-flex align-items-start gap-2 p-3 mt-3 rounded-md bg-warning-container text-on-warning-container`. Use `bg-success-container text-on-success-container` for a good outcome, such as a project closed under budget, and a plain caption when neither applies. The warning callout carries `role="status"`, so assistive technology treats it as a status message.

Milestones are `ITimelineItem[]` in a `UiTimeline size="sm"`. Derive each item's state from the record: finished phases get `icon: '&#xe5ca;'` and `variant: 'success'`, the current one takes the status color, and future ones only a `text: 'Planned'`.

Notes live in a `UiAccordionGroup` beside the timeline. Every `UiAccordion` shares a `name`, so only one stays open, and the first opens by default through `v-model:open`. Use `text` for a paragraph and `#content` for lists (`ps-3 mb-0` with `fs-xs` items).

## Tasks

Group the tasks by status in a computed and drop empty groups. Each group opens with a small `UiBadge size="sm"` (put the count beside it in `caption text-muted tabular-numbers`), followed by a `UiListGroup`.

The checkbox goes in the item's `#media` slot, with a `label` that names the task and `hide-label`. Done tasks stay in their group with `custom-class="{ 'opacity-70': task.done }"`. Put per-task facts (an overdue badge, priority, the assignee's avatar) in `#list-action` and set `has-actions` on the item:

```vue
<UiListItem :title="task.title" :text="task.meta" has-actions>
  <template #list-action>
    <div class="d-flex align-items-center gap-2">
      <UiBadge v-if="task.overdue" text="Overdue" variant="danger" icon-code="&#xe8b5;" size="sm" />
      <UiAvatar initials="LM" alt="Leo Martins" color="accent" size="sm" />
    </div>
  </template>
</UiListItem>
```

Wrap the items in `<TransitionGroup name="list">` to animate them between groups with Colorffy's [list transition](/colorffy-css/utilities/effects#transitions). When no groups are left, show a `UiEmpty` that says where tasks will appear, inside a pane card so the panel keeps the surface the others have.

## Files

`UiInputFile size="lg"` is the drop target, above a `subtitle-1 fw-700` heading with the file count and the list. Handle the file in `@update` and reset the model so the dropbox is ready for the next file.

Give each file type an icon and an intent, and paint the list item's tile with `custom-icon-wrapper-class="bg-<intent>-container"` and `custom-icon-class="text-on-<intent>-container"`. While a file uploads, show it as its own row with a [UiProgressSpinner](/colorffy-ui/components/progress) in the `#media` slot:

```vue
<UiListItem v-for="item in uploading" :key="item.id" :title="item.name" :text="`Uploading · ${item.size}`">
  <template #media>
    <span class="d-inline-flex p-2 rounded-md bg-muted-container text-on-muted-container">
      <UiProgressSpinner size="1.25rem" />
    </span>
  </template>
</UiListItem>
```

Download is an icon-only `UiButtonTooltip` (`variant="text" icon icon-variant="compact" size="sm"`) whose `tooltip-text` names the file. Confirm a finished upload with a toast.

## Activity

The activity panel is one `UiTimeline` in a pane card, newest first. Items with a person behind them set `imageUrl` and `imageAlt` to the actor's avatar; the rest set an `icon` and a `variant` for the kind of event. Prepend the events the user causes on the page (a status change, a completed task, an upload) so the panel reflects them right away.

## Handle an unknown id

When the id matches nothing, render a pane card with `UiEmpty` in place of the page. Pass `use-custom-icon` with the collection's icon, say what may have happened in `subtitle`, and put a filled button back to the collection in `#action`. The `v-if` sits on a `<template>` around the whole page, so the breadcrumb, tabs and panels never render with missing data.

## Design rules

- The breadcrumb ends on the record's name with no link; the first item carries the collection's icon.
- The header holds the actions that change the whole record. Row-level actions stay in their lists.
- Status uses one intent everywhere: the badge, the Status button's `color`, the menu icons and the current milestone.
- Panels are built from pane cards (`UiCard variant="pane"`) and lists. Cards in one row get `custom-class="h-100"`.
- Two-column rows collapse to one column: metric cards split at `col-md-6`, milestones and notes at `col-lg-7` / `col-lg-5`.
- At most one tinted callout per card, and only for a condition the user should act on or a final outcome.
- Counts and amounts use `tabular-numbers` so they don't shift as values change.

## Accessibility

- The breadcrumb is a `<nav>` landmark named "Breadcrumb", and the project name is the page's `h1`.
- Each tab has `aria-controls` from its `panelId`, and each panel is a `role="tabpanel"` labelled by `tab-<id>`. Arrow keys, Home and End move between tabs.
- Progress bars carry an `aria-label` with the record's name and what they measure.
- The budget callout is `role="status"`, and `UiEmpty` is a polite live region by default.
- Task checkboxes keep a `label` ("Mark … as done") and hide it with `hide-label`; the file input does the same with "Upload a file".
- Icon-only buttons get their accessible name from `tooltip-text`.
