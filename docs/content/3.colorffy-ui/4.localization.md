Some text comes from the components themselves rather than your props: button names such as "Clear selection", the "Optional" hint under a field, empty states, screen-reader announcements, and month and weekday names. Set a language once and all of it follows. Labels, placeholders and other text you pass as props stay as you wrote them.

The defaults shown on the component pages are the English texts.

## Set the language

Colorffy UI ships English and Spanish. Pass a language pack and a locale when you install it:

```ts [main.ts]
import ColorffyUI from '@colorffy/ui'
import { es } from '@colorffy/ui/locales/es'
import { createApp } from 'vue'
import App from './App.vue'

createApp(App).use(ColorffyUI, { locale: 'es-SV', labels: es }).mount('#app')
```

With the Nuxt module, name the pack in `nuxt.config`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@colorffy/ui/nuxt'],
  colorffyUI: {
    locale: 'es-SV',
    labels: 'es',
  },
})
```

`locale` sets the order you type dates in, the month and weekday names, and the first day of the week. Without it, components use the page's `lang`, then the browser's language.

## Change a few texts

Your own texts merge over the pack, one group at a time, so you only write what differs:

```ts
app.use(ColorffyUI, {
  locale: 'es-SV',
  labels: {
    ...es,
    dateInput: { ...es.dateInput, apply: 'Listo' },
    common: { optional: '(opcional)' },
  },
})
```

Texts with placeholders keep them in braces, such as `'{count} seleccionados'` or `'Página {page} de {total}'`, so they also work as plain JSON in `nuxt.config`.

## Which text wins

1. A prop on the component, such as `clear-label` or `:labels` on `UiInputDate`.
2. The nearest `UiConfigProvider`.
3. The plugin or Nuxt module options.
4. English.

```vue
<template>
  <UiInputDate v-model="snooze" time :labels="{ apply: 'Posponer' }" />
</template>
```

## One section in another language

`UiConfigProvider` sets the locale and texts for everything inside it, merged over the surrounding ones:

```vue
<template>
  <UiConfigProvider locale="en-US" :labels="en">
    <PartnerPortal />
  </UiConfigProvider>
</template>
```

## Switch language at runtime

`useColorffyConfig()` returns the app's live configuration. Set its `locale` and `labels` and every component updates in place, including an open calendar:

```ts [plugins/colorffy-locale.ts]
import { en } from '@colorffy/ui/locales/en'
import { es } from '@colorffy/ui/locales/es'

export default defineNuxtPlugin(() => {
  const { locale } = useI18n()
  const config = useColorffyConfig()

  watch(locale, (code) => {
    config.locale = code === 'es' ? 'es-SV' : 'en-US'
    config.labels = code === 'es' ? es : en
  }, { immediate: true })
})
```

Inside a `UiConfigProvider`, change its props instead.

## Translate the date presets

The `datePresets` helpers show the `datePresets` texts in the current language, so a list defined once follows a language switch. A `label` you pass still wins:

```ts
const presets = [
  datePresets.today(),           // "Hoy"
  datePresets.lastDays(7),       // "Últimos 7 días"
  datePresets.thisMonth('Mes en curso'),
]
```

The time fields of `UiInputDate` are the browser's native ones, so they follow the browser's language and 12- or 24-hour clock rather than `locale`.

## Write a language pack

A pack is an object with every group. Type it with `IColorffyLabels` so the editor flags a missing or misspelled text:

```ts [locales/fr.ts]
import type { IColorffyLabels } from '@colorffy/ui'

export const fr = {
  common: { optional: 'Facultatif' },
  combobox: { empty: 'Aucun résultat', clear: 'Effacer la sélection', toggle: 'Afficher les options' },
  pagination: { ariaLabel: 'Pagination', first: 'Première page', previous: 'Page précédente', next: 'Page suivante', last: 'Dernière page', status: 'Page {page} sur {total}' },
  // …every other group
} satisfies IColorffyLabels
```

| Group | Covers |
|-------|--------|
| `common` | The "Optional" hint of every input |
| `alert`, `chip` | Close and remove buttons |
| `avatar` | The image description when there's no `alt` |
| `breadcrumb`, `navbar`, `navigationBar`, `sidebar`, `buttonToggleGroup` | Landmark and group names, navbar images and the sidebar toggle |
| `calendar` | Calendar name, month buttons and the range announcement |
| `combobox`, `multiSelect`, `select`, `tags`, `search`, `password`, `otp` | Input buttons, empty lists, summaries and announcements |
| `confirmModal` | Confirm, cancel and loading buttons |
| `datatable` | Column manager, empty state and selection checkboxes |
| `dateInput`, `datePresets` | Date field buttons, From / To, Now, typing hint letters and preset names |
| `empty`, `loading` | Names of empty states, spinners and skeletons |
| `header`, `popoverMenu` | Back button, page actions, menu names and the profile photo |
| `pagination` | Arrow names and the "Page 3 of 12" text |

The full list, with each text's English value, is in the `IColorffyLabels` type and in `@colorffy/ui/locales/en`.
