Colorffy CSS is built to be customized — override variables at build time or CSS custom properties at runtime.

## Set brand colors and fonts

Theme colors and fonts are CSS custom properties, so the same override works with the compiled CSS and with the SCSS source. Put it in your own stylesheet: it wins over the framework's layered defaults whatever the import order.

```css [theme.css]
:root {
  /* each theme color has a light-mode (-500) and dark-mode (-50) tone */
  --color-brand-primary-500: oklch(45% 0.2 275);
  --color-brand-primary-50: oklch(90% 0.06 275);
  --color-brand-secondary-500: oklch(62% 0.2 350);
  --color-brand-secondary-50: oklch(92% 0.05 350);

  --font-primary: 'Inter', sans-serif;
  --font-secondary: 'Inter', sans-serif;
}
```

Brand tokens exist for `primary`, `secondary`, `accent`, `success`, `warning`, `danger`, `info` and `muted`. The tonal steps (`--theme-primary-a10` … `a90`) and every component derive from them. To use one color in both modes, set `--theme-primary-base` instead.

::note
The `$primary`, `$secondary`, `$accent` and `$font-*` SCSS variables don't recolor components or change fonts; they only feed compile-time details such as the button ripple. Set the tokens above.
::

## Override SCSS variables

A few component defaults are compile-time SCSS variables. Set them with `@forward ... with` **before** importing the framework:

```scss [theme.scss]
@forward '@colorffy/css/scss/abstracts/variables' with (
  $button-border-radius: 4px,
  $card-border-radius: 8px,
  $form-border-radius: 4px,
  $dialog-border-radius: 12px,
);

@use '@colorffy/css/scss/main';
```

## Use mixins and functions

```scss
@use '@colorffy/css/scss/abstracts/mixins' as mix;
@use '@colorffy/css/scss/abstracts/functions' as fn;

.hero {
  @include mix.flex-center;
  @include mix.glass-effect;
  @include mix.text-gradient(45deg, (#ff0080, #ff8c00));
}
```

## Customize in Nuxt 3

Feed your variables into every SCSS file via Vite:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['~/assets/scss/main.scss'],
  vite: {
    css: {
      preprocessorOptions: {
        scss: {
          additionalData: '@use "~/assets/scss/variables.scss" as *;',
        },
      },
    },
  },
})
```

## Override at runtime

```css
:root {
  --theme-primary-base: #4f46e5;
}

/* component variables are declared on the component, so target it */
.btn {
  --_btn-radius: 50px;
}
```

A component variable set this way applies to every variant of that component.

## Shape, weight & motion tokens

Radius, border width, font weight, easing and the focus ring are CSS custom properties on `:root`, and the components read them. Override them at runtime, globally or for one subtree, without recompiling the SCSS:

```css
:root {
  --radius-md: 10px;
  --border-width-sm: 1.5px;
  --fw-600: 650;
  --ease-decelerate: cubic-bezier(0.2, 0, 0, 1);
  --focus-ring-color: var(--theme-primary-a10);
}
```

| Token | Default |
|-------|---------|
| `--radius-none` / `-sm` / `-md` / `-lg` / `-xl` / `-full` | `0` / `6px` / `8px` / `12px` / `25px` / `50px` |
| `--border-width-sm` / `-md` | `1px` / `2px` |
| `--fw-400` … `--fw-800` | `400` … `800` |
| `--ease-decelerate` / `--ease-accelerate` | Standard enter / exit curves |
| `--ease-spring`, `--ease-overshoot-soft`, `--ease-emphasized`, `--ease-bounce`, `--ease-power-in`, `--ease-power-in-out`, `--ease-sine-in-out` | `linear()` curves |
| `--focus-ring-color` / `--focus-ring-offset` | `--theme-on-background` / `.3rem` |

Under `prefers-reduced-motion: reduce`, `--ease-spring`, `--ease-overshoot-soft` and `--ease-bounce` resolve to `--ease-decelerate`, so nothing overshoots or bounces.

The SCSS variables (`$rounded-*`, `$border-sm`, `$fw-*`, `$easing-*`) still exist and set these tokens' defaults.

## Spacing & type tokens (2.5+)

All component spacing flows through the `--space-*` tokens, and every step is
derived from one base unit — so density is a runtime one-liner:

```css
/* scale the whole UI's spacing to 80%, globally or per subtree */
.dense-dashboard { --space-unit: .2rem; }

/* or retune a single step */
:root { --space-12: .7rem; }
```

Font sizes use the `--fs-*` t-shirt scale (`--fs-4xs` … `--fs-5xl`, anchored
at `--fs-base`), each with a `--fs-{step}--line-height` companion:

```css
:root {
  --fs-base: 1rem;              /* opt out of fluid sizing */
  --fs-base--line-height: 1.6;
}
```
