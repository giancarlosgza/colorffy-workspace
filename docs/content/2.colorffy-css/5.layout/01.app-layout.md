Colorffy CSS ships the styling for full app scaffolding. These classes back the matching Vue components in Colorffy UI — use the components for behavior, or the classes directly if you're CSS-only.

## Navbar

`.navbar` (top bar) with `.nav-sticky` for sticky positioning, plus regions like `.menu-tools-container`, `.popover-menu-container`, and `.sidebar-collapse-button`.

→ Component: [Navbar](/colorffy-ui/components/navbar)

### Menu tools CSS variables

The mega menu (`.menu-tools`) reads these variables. Set them on `:root` or on the `.menu-tools-container`. Hovered and active links keep their own wider radius. Hover and pressed backgrounds come from the shared [state layer](/colorffy-css/customization#hover-and-pressed-states).

| Variable | Default | Controls |
|----------|---------|----------|
| `--menu-tools-bg-color` | `--theme-surface-body-pane` | Panel background |
| `--menu-tools-shadow` | `--shadow-sm` | Panel shadow |
| `--menu-tools-radius` | `--radius-lg` | Panel, tab and link corners |
| `--menu-tools-padding` / `--menu-tools-gap` | `--space-12` / `--space-14` | Inner padding and spacing |
| `--menu-tools-max-height` | `28rem` | Scrollable content height |
| `--menu-tools-easing` / `--menu-tools-duration` | `--ease-emphasized` / `--duration-600` | Opening animation |
| `--menu-tools-tabs-bg-color` | `--theme-background` | Tabs column background |
| `--menu-tools-tab-active-bg-color` / `--menu-tools-tab-active-color` | `--theme-surface-body-pane` / `--theme-primary-a30` | Selected tab and its title |
| `--menu-tools-link-active-bg-color` / `--menu-tools-link-active-color` | `--theme-surface-container-high` / `--theme-primary-a10` | Current-route link and its title |

## Sidebar / navigation drawer

`.navigation-drawer` with modifiers `.drawer-bordered`, `.drawer-rail`, `.drawer-open` / `.drawer-closed`, and `.drawer-overlay` for the mobile scrim. Regions: `.drawer-header`, `.drawer-body`, `.drawer-footer`.

→ Component: [Sidebar](/colorffy-ui/components/sidebar)

## Bottom navigation bar

`.navigation-bar` — a mobile / island bottom navigation bar.

→ Component: [Navigation Bar](/colorffy-ui/components/navigation-bar)

## Header & footer

- `.header-container` / `.header` — page header band
- `.footer` — page footer

::note
These structural pieces are styled but behavior-light. For interactivity (toggling the drawer, sticky state, dropdowns), use the [Colorffy UI](/colorffy-ui/usage) components, which wire it all up.
::
